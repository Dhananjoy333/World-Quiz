# 🌍 WorldQuiz

A fun geography quiz game built with **React** where players test their knowledge of world countries and capitals.  
Players can compete on a **global leaderboard**, track their **high scores**, and improve their geography knowledge while playing.

---

## 🎮 Game Modes

Currently the game includes two quiz modes:

### 🏳️ Flag Quiz
Guess the **country name** by looking at its **flag**.

### 🌆 Capital Quiz
Guess the **capital city** from the **country name**.

More game modes will be added in future updates.

---

## ✨ Features

- 🎮 Multiple quiz game modes  
- 🏆 Global leaderboard system  
- 📈 Personal high score tracking  
- 🔐 User authentication with Clerk  
- 🎵 Background music and sound effects  
- ⚡ Fast React interface with dynamic questions  
- 🌐 REST API integration with backend  
- 🎨 Retro pixel-style UI
